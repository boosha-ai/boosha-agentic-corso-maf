*The Village* (2004) e *Lady Bird* (2017), salvato il 2026-10-02 con `_sezione_critica`.
Servono ai test per girare senza rete. Testo di Wikipedia, licenza CC BY-SA 4.0:
https://en.wikipedia.org/wiki/The_Village_(2004_film) e https://en.wikipedia.org/wiki/Lady_Bird_(film).
